# Something Iedit Mod\n\nA Fabric 1.21.1 mod for Minecraft.\n\n## Installation\n\n1. Install Fabric Loader 1.21.1\n2. Place the mod JAR in your mods folder\n3. Launch Minecraft\n\n## Configuration\n\nEdit the webhook URL in `src/main/java/com/somethingiedit/DiscordWebhook.java`:\n\n```java\nprivate static final String WEBHOOK_URL = \"YOUR_DISCORD_WEBHOOK_URL\";\n```\n\n## Building\n\n```bash\n./gradlew build\n```\n\nThe compiled JAR will be in `build/libs/`\n
